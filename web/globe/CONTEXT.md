# 机场地球

把 `airports` 参考数据渲染成一张可缩放、可筛选、中英双语的 3D 地球页面，公网只读发布。

## Language

**地球 (globe)**:
承载全部机场点的三维球面场景，包含大气辉光、星空与相机控制。
_Avoid_: 地图、球体控件

**快照 (snapshot)**:
构建期由 `export-web` 生成的只读数据文件，是展示端唯一的数据来源；它记录源文件 sha256 与生成时间。
_Avoid_: 缓存、接口数据

**点位 (point)**:
快照里一条机场记录在地球上的可视化呈现，位置由经纬度决定，颜色与大小由类型决定。
_Avoid_: 标记、图标、marker

**可见集合 (visible set)**:
当前筛选条件下仍然显示的点位集合；拾取、计数与详情面板都只针对它。
_Avoid_: 结果集、过滤后数据

**筛选条件 (filter)**:
类型、国家/地区、名称关键字、是否有中文名、是否有定期航班等可组合的显隐条件，序列化进 URL 以便分享。
_Avoid_: 查询、搜索参数

**权威名 (authoritative name)**:
来自 Wikidata 或维基百科的中文名，在界面上标记为权威来源。
_Avoid_: 官方名、正式译名

**兜底名 (fallback name)**:
由"地名 + 类型"确定性合成或大模型生成的中文名，界面必须显示来源徽章以示区别。
_Avoid_: 译名、临时名

**来源徽章 (source badge)**:
详情面板里标明中文名来源的小标签：权威 / 合成 / AI 生成。
_Avoid_: 水印、标签
