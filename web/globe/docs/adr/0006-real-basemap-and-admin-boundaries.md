# 真实底图用瓦片引擎，省/市轮廓按缩放叠加

线框地球缺少地理参照，因此底图改为**真实影像**：用 globe.gl 内置的瓦片引擎
（`three-slippy-map-globe`，标准 XYZ 瓦片）加载栅格瓦片，而不是把地球贴一张大图。

- `实景卫星`（默认）：EOX Sentinel-2 cloudless 2020 WMTS（EPSG:3857），免 key、CORS 已放开，
  许可 CC BY-NC-SA 4.0，页脚常驻署名；**非商业**使用才适用，商业化需换源。
- `街道`：OpenStreetMap 标准瓦片，用于看路网与地名；按 OSM 瓦片使用政策仅供轻量使用，
  若流量上来应换商业瓦片或自建。
- `线框`：保留极简风格（Natural Earth 轮廓 + 深色球体），弱网或断网时的兜底。

行政区轮廓继续走 Natural Earth（公共领域），但拆成三个图层，各自按缩放升级：

| 图层 | 出现时机 | 数据 | 文件（gzip） |
| --- | --- | --- | --- |
| countries | 始终 | 110m → 50m → 10m | 45 KB / 355 KB / 2.0 MB |
| provinces | 相机距离 ≤240（区域级） | 50m → 10m admin-1 | 261 KB / 2.3 MB |
| districts | 相机距离 ≤112（城市级） | 10m admin-2 | 496 KB |

`districts` 只有**美国县**——Natural Earth 的 admin-2 只覆盖美国，全球范围的"市"级边界需要
OSM/商业数据源，属于后续可选工作；因此这一层描述成"县/市"而不是承诺全球市界。所有图层都是
懒加载、只向更细升级、可整体关闭（`borders=0`），且不参与点位拾取（边界只是背景线）。
