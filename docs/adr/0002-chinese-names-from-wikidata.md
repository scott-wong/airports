# 中文名全部自动生成，并冻结为仓库内版本化 CSV

OurAirports 没有中文字段，而大型/中型机场的中文名与城市名是公开知识、变化缓慢。选择自动
生成：机场名按 IATA(P238) → ICAO(P239) 匹配 Wikidata 实体，要求实体属于机场类且坐标距离
≤25km，标签按 zh-cn > zh-hans > zh > 繁体转简体 取值；城市名按 OurAirports 的 municipality
字段匹配英文维基条目并取中文跨语言链接，要求条目分类属于居民点、排除消歧义页；机场所在地
另用 P131 中的人类聚居地（多个人选取人口最多者）。生成结果冻结成
`data/airport_names_zh.csv` 提交进仓库，采集时只读该文件，不在采集链路里调用翻译或 LLM ——
目的是让每条中文名可 diff、可复现、可追溯。

三处取舍值得记住：

- 解析不到时留空并标 `unresolved`，不做机器翻译：给非洲/中亚小机场编一个并不存在的
  “中文名”，比留空更有害。
- `municipality_zh`（服务城市）与 `location_zh`（所在地聚居地）分列存放。Wikidata P131 对
  北京大兴机场给的是九州镇——地理上正确，但拿它当“服务城市”是语义错位，所以拆成两列。
- P131 只接受人类聚居地（Q486972 及其子类）：否则所罗门群岛的机场会得到“瓜达尔卡纳尔省”
  这种省名当城市名的结果。
