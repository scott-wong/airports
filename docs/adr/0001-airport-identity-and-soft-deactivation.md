# 以 OurAirports 整数 id 作为机场身份，源端消失时标记失活而不是删除

OurAirports 字典明确说明 `id` 在机场代码变化时也保持持久，而 `ident` 会随 ICAO/本地码变化，
因此本地身份用 `id`，`ident` 只做唯一的外部可见标识。上游 CSV 是每日全量快照，某轮快照里
缺失的 `id` 无法区分“机场被删除”和“上游临时漏发”，所以不物理删除，只把 `is_active` 置为
false 并记录 `deactivated_at`；重新出现时自动复活。这一决定代价低但影响所有读取方（必须
理解失活行的存在），且与源端 `type='closed'` 是两个互不推导的维度，故此记录。
